## Codebase Patterns
- Project uses Next.js App Router with "use client" directives
- Tailwind CSS v4 with @import "tailwindcss" syntax
- Framer Motion for all animations (motion, AnimatePresence)
- @react-three/fiber + drei for 3D scenes
- Color palette: Saffron #D4882F/#FF9933, Green #2A7B3A/#138808, Navy #0A1F44
- HeroPremium.jsx is the main hero section, uses CinematicScene.jsx for 3D
- Custom cursor system with .cursor-dot and .cursor-ring classes
- Buttons use touch-action: manipulation for mobile
- Glassmorphism buttons use .glass-btn class with --saffron/--green/--navy variants
- 3D canvas sits at z-0, vignette at z-[1], content at z-10 — buttons must be in z-10 div
- Register button uses onClick + setTimeout + router.push pattern for premium transition
- pointer-events: auto on individual buttons ensures clickability over 3D canvas
